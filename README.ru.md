# Claude Desktop Guard

Отдельное приложение для **Claude Desktop, вкладки Code**, на Windows и macOS.

Вы выбираете интерфейс Amnezia VPN или локальный HTTP-прокси, проверяете выход, явно закрепляете IP и страну. Guard запускает Claude через свой барьер и закрывает туннели при смене выхода, узла Mihomo или ошибке проверки.

Это контроль маршрута. Доказанной защиты от бана нет: серверные правила аккаунта остаются у Anthropic.

## Запуск

1. [Скачайте сборку](https://github.com/w1zardz/claude-desktop-guard/releases) под Windows x64, Apple Silicon или Intel Mac. Сборки без подписи и нотариализации; применяются обычные правила допуска приложений вашей ОС.
2. Полностью завершите Claude Desktop. Минимальная версия — `1.44121.1`; контракт локальной конфигурации изучен на `2.19675.0`.
3. Запустите VPN. Для **AmneziaWG** выберите режим **Amnezia VPN**, обновите список и явно выберите активный интерфейс с его индексом и IPv4-адресом. HTTP-вход Amnezia не нужен. Для Clash/Mihomo выберите **Локальный прокси** и введите его HTTP-адрес. SOCKS, чужие адреса и пароли в URL не принимаются.
4. Нажмите **Проверить выход**, затем **Закрепить этот IP**. Скрытого выбора адреса, страны или узла нет.
5. В режиме локального прокси при необходимости задайте контроллер Mihomo, группу и конкретный конечный узел. Настройте правила самого Mihomo; Guard проверяет выбранную группу, но не подменяет ваши правила.
6. При необходимости включите **Часовой пояс и язык Claude**. Кнопка копирует пояс и страну проверенного выхода; язык задайте явно. Затем нажмите **Запустить Claude через Guard**. Работайте в локальной Code-сессии.

При ошибке проверки новые и открытые туннели закрываются. Барьер сам не открывается обратно. Закрытие окна сворачивает Guard в трей; остановка оставляет Claude привязанным к закрытому прокси. Для возврата прежнего маршрута завершите Claude и нажмите **Восстановить настройки**.

## Что важно

- Прямого резервного соединения у барьера нет. HTTPS остаётся зашифрованным: промпты не переписываются, выдуманная история не добавляется.
- В режиме Amnezia встроенный помощник привязывает IPv4 TCP-соединения к выбранному VPN-интерфейсу и его адресу средствами ОС. DNS через HTTPS тоже идёт через него. Системный DNS не используется; IPv6-назначения отклоняются. Исчезновение интерфейса закрывает соединения; автоматического переподключения нет.
- Если в Amnezia выбран режим **«VPN для всего, кроме выбранных сайтов»**, список сайтов — исключения для прямого выхода. Claude/Anthropic туда добавлять нельзя. Guard список маршрутов и VPN-ключи не меняет.
- После переподключения VPN индекс или адрес могут измениться: обновите список, выберите интерфейс заново, проверьте и закрепите выход.
- Проверки идут через ipify и ipinfo каждые 10 секунд. Их сбой или ограничение запросов тоже блокирует доступ.
- Наблюдение IP не доказывает маршрут каждого домена при раздельных правилах прокси.
- Windows требует отдельного VPN kill switch/firewall для блокировки всех прямых соединений.
- Правило WFP только для каталога Claude не охватывает отдельный прокси-процесс. Привязка встроенного помощника защищает его соединения; остальные процессы требуют своего контроля.
- Строгий режим macOS ограничивает сеть запущенного дерева процессов. Команды без поддержки HTTP-прокси, локальные previews/MCP/browser bridge могут перестать работать.
- Обновления, вход во внешнем браузере, Cloud, SSH, WSL и отдельные системные службы требуют своих сетевых настроек.
- Проектные настройки `.claude/settings*.json` могут переопределить пользовательский прокси. Ранее запущенные фоновые процессы не входят в новую песочницу. Guard не переписывает проектные файлы.
- Часовой пояс и язык задаются **до запуска Claude** через окружение и параметры Chromium. На Mac также задаются предпочитаемые языки и регион через временные параметры Cocoa только для процесса Claude. Часовой пояс и язык самой ОС сохраняются. Пояс профиля должен совпадать с поясом проверенного выхода; отсутствие или изменение этого значения блокирует барьер.
- В Windows предпочитаемые языки и региональные API ОС остаются доступны Claude. Изменение системного часового пояса Windows может сбросить пояс Chromium до перезапуска Claude. Сохранённый язык интерфейса Desktop тоже может отличаться от языка Chromium.
- Guard различает «параметры переданы» и реальное измерение в Claude. Результаты проверки настоящего Mac-приложения и воспроизводимые тесты находятся в [протоколе проверки](docs/client-validation.md).
- Профиль не скрывает ОС, User-Agent, RAM/класс устройства, GPU, шрифты, Canvas/WebGL, TLS или историю аккаунта. Браузерное расширение `notme` не внедряется в Desktop.
- При восстановлении сохраняются обнаруженные чужие изменения. Обнаруженный конфликт прекращает автоматическое восстановление; журнал остаётся локально. Закройте другие редакторы настроек: их записи Guard не блокирует. Резервная копия может содержать ваши секреты.
